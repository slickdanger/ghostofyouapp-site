Fonts served by this site
=========================

Both families are licensed under the SIL Open Font License 1.1, which permits
self-hosting. The full licence text for each is in this folder.

  archivo-latin.woff2         Archivo, VARIABLE. Latin subset.
                              Axes confirmed by reading the font's own fvar table:
                                wght  100 – 900   (default 600)
                                wdth   62 – 125   (default 100)
                              The width axis is what makes font-stretch: 112%
                              work. Without it the headlines would silently
                              render at normal width.
                              Licence: OFL-Archivo.txt

  instrumentsans-latin.woff2  Instrument Sans, VARIABLE. Latin subset.
                              Axis confirmed the same way:
                                wght  400 – 700   (default 400)
                              Covers the 400 / 500 / 600 weights the page uses.
                              Licence: OFL-InstrumentSans.txt
